# Half-Marathon NYRR Source Extraction

Source files: `WorkoutPlan/Half Marathon Training Plan Conservative.pdf`, `Moderate-1.pdf`, and `Advanced.pdf`.

Extraction was completed from both pages of each PDF. The first page supplies entry text and ten-week tables; the second page defines the workout-category terms.

Preserved facts:

- Conservative: 3-4 running days, approximately 40-minute longest run, new to speed work.
- Moderate: 4-5 running days, approximately 60-minute longest run, familiar with speed work.
- Advanced: 5-6 running days, approximately 80-minute longest run, challenging workouts.
- All three sources use ten weeks and have an unspecified race duration.
- Cross-training/rest and alternatives are source options, not compulsory RunSensei sessions.
- Distance/time ranges and strides remain ranges. The candidate generator does not turn them into a pace target.

Unresolved source contradiction:

- Advanced Week 3 Sunday states "1 hour and 50 minutes" and "100 minutes". The source record remains ambiguous; no candidate policy depends on selecting either source value.

Copyright boundary: these references are used internally for evidence context. The RunSensei draft policy is original candidate content and is not a reproduction of the source tables.
